# Public synthetic contract examples

These JSON files illustrate v0.1 contracts, not completed renders. Names, text and hashes are synthetic; referenced media files do not exist. `mvt validate` checks a single artifact and intentionally does not assert media readiness. S01/S05 add project/media preflight; S02 creates real synthetic rendering fixtures.

`plan-abstract.json`, `plan-mood.json`, `plan-hybrid.json` share a timeline and layer shapes. Hybrid reuses the A and B layers. Lyrics are optional; the hybrid example points to saved imported cues. `preview.json` shows named global sample ranges. `render.json` is an illustrative manifest, not evidence that a video was produced.
