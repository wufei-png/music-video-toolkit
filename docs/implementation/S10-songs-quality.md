# S10 — 两首歌成片与开源使用就绪

状态：完成（2026-09-18）。依赖：S09。

## 独立交付

两首本地歌曲的 C 全曲成片，展示 A/B 可配置复用；把真实反馈推动的通用修复纳入工具和文档。

## 输入输出

输入：外层 projects/ 两个案例、歌词与音频、用户选择/生成的外部意境素材。输出：两首1080p30 MP4、批准样片/反馈、render manifests、公开安装示例和测试结果。

## 实现范围与方法

拥有通用质量修复、case workflow、release checklist 和 tests/stages/test_s10.py；真实材料/歌词/结果在外层。先每首30–60秒多片段，记录并处理用户反馈，再全曲。画面风格留在 case 配置；可复用的层级/参数/排版/转场问题反馈工具。

## 验收契约

两首完整时长音画端点误差≤1帧（解释编码 padding），无丢帧、黑帧故障/缺素材/乱码/可听 clipping。抽检稀疏、高潮、转场和尾声，审阅歌词关键重复段，用户确认整体视觉质量。生成同 timeline 的 A/B 短例证明复用。干净环境按公开说明安装并运行合成 demo；真实歌曲不作为公开安装测试前提。

## 实施时创建并执行的检查

`uv run --locked pytest`；`pnpm --dir renderer check`；所有真实 integration gates；ffprobe/media QA；用户样片/成片反馈记录。

最终回归运行本片测试与所有已完成切片回归，不能依赖后续片的实现。

## 边界与失败处理

用户已于 2026-09-17 确认细体艺术字、确定性 3D 鼓起光照和透明拖影方向。两首全曲均完成端点、帧数、编码、黑场、峰值与接触表检查。生成媒体、歌词、字体副本和反馈仍只保存在外层本地工作区。不自动推送、建远端或发布；公开素材另按来源与用户授权处理。

## 提交与交接

检查 tracked/untracked/ignored，显式 stage 本片代码、测试与状态文档，检查 staged diff 和 `git diff --check --cached` 后提交。更新 status：实际命令/版本、通过或失败、真实集成证据位置、尚未完成的用户审阅，以及下一片。没有通过的 live gate 不能记录成完成；必要时只记录受阻的工作进度，避免伪造验证结果。
